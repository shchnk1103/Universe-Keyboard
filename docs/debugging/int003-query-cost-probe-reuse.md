## 后续使用的必要条件

每轮先绑定独立Assignment/AUTH、源码/安装身份、实际route/scope、独占设备、公开fixture与停止条件。Luna显示为当前使用和Full Access开只说明配置，不证明probe的实际facade/session可用。出现“不可启用”保留一次结果，读取有限arm诊断；不要反复要求Human预热、重复点击或猜修。

四按钮为“观测成本／序列边界／成本取证／时间锚点”，仅成本探针宏开启时出现，保持候选栏左侧并与右侧关闭键分开。一次arm，有限序列；导出在输入测量结束后一次freeze，pointer仅在有效borrow内读取。保留两份一致副本、完整性、scope、计数和字节/hash，安全分离调试器。接受/排除额外输入由Human批准实际mapping，不篡改raw标签，不以重复一次直接推定必须重录。
