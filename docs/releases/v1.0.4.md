## What's New（商店更新文案草案）

**中文：**

> 本次更新带来三项改进：
> - 修复触感反馈问题：开启按键振动后，现在可以正常再次关闭该开关。
> - 首页更简洁：移除了长按空格的操作引导横幅。
> - 九宫格数字键盘手感优化：数字面板支持下滑收起，键盘高度随之平滑调整。

**English:**

> This update includes three improvements:
> - Haptics fix: after enabling key vibration, the toggle can now be turned off again as expected.
> - A cleaner home screen: removed the long-press space bar onboarding banner.
> - Nine-key number pad refinements: the number pad now supports swipe-down to collapse, with the keyboard height adjusting smoothly.
