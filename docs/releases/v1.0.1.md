## 1. 包含的用户可见改动

1. `KEY-ROLLOVER-001`：普通键按下序重叠与触区一致性修复；按键消费、抬手抑制双写与长按变体恢复保持一致。来源见 [CHANGELOG.md](../../CHANGELOG.md) 2026-11-16 条目。
2. `KEY-LABEL-READABILITY-001`：字符键外观设置与分键盘大小写；中文 26 键与九宫格默认大写，英文 26 键跟随 Shift，中文大写只改显示、不改送给 RIME 的编码。来源见 [CHANGELOG.md](../../CHANGELOG.md) 2026-11-17 条目。
3. `T9-PINYIN-CYCLE-005`：九宫格选拼音视口与预选删除；连续选拼音时只保证选中项可见，预选后按数字再删除会回到按数字前的输入与预选。来源见 [CHANGELOG.md](../../CHANGELOG.md) 2026-11-14 条目；真机仍待验。
4. `PASTE-COPY-A-001`：App 隐私页剪贴板说明对齐；双开关、仅内存、每次出现最多读一次。来源见 [CHANGELOG.md](../../CHANGELOG.md) 2026-11-14 条目与 [PRIVACY_POLICY.md](../PRIVACY_POLICY.md)。

CI 与 KOS 工具改动（`pr_flow.py` 重试、测试分级、模板升级）不列为 1.0.1 用户可见功能。

[PRIVACY_POLICY.md](../PRIVACY_POLICY.md) 与 App 内隐私页（PR #303）已统一口径：完全访问与主 App 开关同时开启时，键盘每次出现最多读取一次剪贴板文字，用于预览和粘贴；内容仅内存、不保存、不上传；任一项未开启时不读取、不显示粘贴条，打字仍可用。仓库当前未发现过时「脱敏」字样。提审隐私问卷与 Review Notes 必须按同一口径填写；问卷提交与 Review Notes 最终措辞仍由 Human 确认。

### App 审核备注（Review Notes 建议稿）

本版本使用本地离线 RIME 引擎处理输入；键盘不会把按键、候选、上下文或剪贴板内容上传开发者服务器。剪贴板预览仅在「完全访问」与主 App「显示剪贴板预览」开关同时开启时启用；键盘每次出现最多读取一次剪贴板文字，仅保存在内存中用于预览和粘贴，不写入词库、输入洞察或日志，也不上传。关闭任一开关时基础输入仍可用，且不读取剪贴板。App 内置的朙月拼音、essay、prelude、stroke 使用 LGPL-3.0 资料，opencc 使用 Apache-2.0 资料，完整第三方许可与署名随 App 打包；雾凇等第三方方案不属于内置资源，仅在用户主动下载安装时按方案目录展示许可。以上措辞提交前须由 Human 按最终隐私问卷与合规决定确认。
