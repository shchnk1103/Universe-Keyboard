### App 审核备注（Review Notes）

本版本使用本地离线 RIME 引擎处理输入；键盘不会把按键、候选、上下文或剪贴板内容上传开发者服务器。剪贴板预览仅在「完全访问」与主 App「显示剪贴板预览」开关同时开启时启用；键盘每次出现最多读取一次剪贴板文字，仅保存在内存中用于预览和粘贴，不写入词库、输入洞察或日志，也不上传。关闭任一开关时基础输入仍可用，且不读取剪贴板。App 内置的朙月拼音、essay、prelude、stroke 使用 LGPL-3.0 资料，opencc 使用 Apache-2.0 资料，完整第三方许可与署名随 App 打包；雾凇等第三方方案不属于内置资源，仅在用户主动下载安装时按方案目录展示许可。以上为提交用文案存档；最终措辞以 App Store Connect 提交版本为准。
