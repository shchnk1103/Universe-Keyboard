# M2 人工操作卡（Prepared，禁止现在执行）

由root逐张下发；只适用于M0保护与M1新实例Entry通过且M2获执行授权的原iPhone18Pro/iOS27.0模拟器405D994F-28CB-4F89-BB22-B64AD81C05A2。保持两项诊断关闭、完全访问开启，Maps空搜索框／拼音字母布局；不输入个人地点，不发送搜索、不拍带宿主内容的证据图。

1. **就绪**：root核唯一新PID、模块、出口断点0hit并continue。Human只确认空候选、“观测”可见且未点过；等待窗口／身份不符就停止，不先输入。
2. **arm**：点“观测”一次、松手，回报是否显示“取证”。最多观察30秒，实际未计秒写NOT MEASURED；不再次点击。失败停止。
3. **正常基线**：仅按n一次，停手；回报“按键反馈／候选是否更新／输入框是否更新／取证是否可见”，不抄候选或宿主文字。不选词、不提交、不删除。候选正常且取证可见才继续；输入框表现独立记录，不将composition视觉等同host提交。
4. **唯一切换**：只打开App切换器，直接点Maps卡片返回，不切系统设置或别的App。回报键盘是否有关闭重开动作及取证是否仍可见。root只读核原PID仍同一路径／SHA且session仍运行；PID变化、键盘重开、变成“观测”或无法确认则停止，不再arm。600秒TTL包含等待与这些核验时间。
5. **返回后输入**：只按n一次并停手，分别回报反馈、候选变化、输入框变化，不描述文本。无论目标症状是否复现，都不追加按键；armed候选栏松手至少2秒后应可见“取证”。未出现最多观察30秒，停；不能选词或删除来清空候选。
6. **freeze**：收到root读取就绪卡后点“取证”一次并松手。断点暂停期间键盘短暂不响应是调试暂停，不算故障复现；故障表征必须来自本卡之前。不要点第二次或补输入。
7. **Exit**：root完成一次有界导出并delete/list/continue/detach后，Human只观察界面与标题，回报即可。不追加试打、删除、切App或重新部署；如需恢复交互由root另列具体切片。

任何误触，立刻按原话报告操作／阶段并停手，不补做来凑协议。两个输入必须属于同一run，第一次基线、第二次返回后，由全账本及attempt唯一顺序绑定；没有可配对第二attempt就记录未覆盖，不推owner为空。
